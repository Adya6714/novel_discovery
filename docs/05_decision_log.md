| D13 | Introduced continuation-until-gate (blocks of 6000 steps, cap 22,000) instead of excluding unconverged models | Excluding non-converged K = 3, 4 models would bias the K-curve |
| D14 | **Redesign: abandoned the `x..x SEP c..c` layout (sweep v1) for the interleaved layout `x1 c1 x2 c2 …`.** Sweep v1 checkpoints kept in `runs/sweep_v1_abandoned` (not used for claims) | Discovered that per-batch training loss was misleading (batches with L ≤ K never exercise the window subtraction): K = 5, 6, 8 models had logged loss 2e-4 but chance accuracy at slots j ≥ K. Root cause: in the v1 layout the offset between query and the leaving element is L + K, which varies with L; with learned absolute positions this makes the subtraction step very hard to learn and is a confound unrelated to the read/recompute contrast. In the interleaved layout every operand of both strategies sits at a fixed relative offset. Added fixed-L=12 eval loss/acc to training logs. Validated the intervention metric on exact READ / RECOMPUTE oracle models (FOLLOW = 1.00 / RECOMPUTE = 1.00). Hypotheses H1–H3, metrics, gate and analysis are unchanged |
| D15 | Deviation: training length fixed at L = 12 (was L ~ U{2..12}); 6000 steps + continuation-until-gate (cap 18,000) | Interleaved pilot showed failures only at slots rarely trained under uniform L (K=4 correct at slots 1–10, wrong at 11–12) — a position-coverage confound irrelevant to the read/recompute question. Pilot (variable L, 4000 steps) observations recorded: K=2 RECOMPUTE ≈1.00; K=12 FOLLOW ≈1.00; K=4 FOLLOW = 1.00 on learned j ≥ K slots |
| D16 | Sweep restarted with 3000 steps per model (continuation blocks of 3000, cap 18,000) | With fixed L = 12, the first four models (K = 1–4) had eval accuracy 1.000 at step 2000; 6000 steps would have cost ~2.8 h wall time. No results had been evaluated |
